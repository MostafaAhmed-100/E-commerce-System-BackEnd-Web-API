# E-commerce System (Back-End Web API) 🛒

هذا المشروع عبارة عن **RESTful API** متكامل لنظام تجارة إلكترونية، تم تطويره كـ "مشروع تخرج" خلال فترة تدريبي في شركة **MOGO**.

## 🚀 الميزات التقنية (Technical Features)
- **Authentication & Authorization:** تأمين البيانات باستخدام **JWT (JSON Web Tokens)**.
- **Database Management:** التعامل مع البيانات باستخدام **Entity Framework Core**.
- **Design Patterns:** تطبيق الـ **Repository Pattern** لفصل منطق البيانات عن الـ Controllers.
- **API Documentation:** استخدام **Swagger** لتجربة الـ Endpoints بسهولة.
- **Scalability:** بناء هيكل كود نظيف (Clean Code) قابل للتوسع.

## 🛠 التكنولوجيا المستخدمة (Tech Stack)
- **Framework:** ASP.NET Core Web API
- **Language:** C#
- **Database:** SQL Server
- **Tools:** Postman, LINQ, EF Core.

## 📝 ملاحظة أمنية
تم إزالة مفاتيح التشفير وبيانات الاتصال بقاعدة البيانات من ملف الـ `appsettings.json` لأغراض أمنية. يرجى إضافة بياناتك الخاصة لتشغيل المشروع.

## 🏗️ كيف تبدأ؟
1. قم بعمل `Clone` للمشروع.
2. أضف الـ `Connection String` والـ `JWT Key` الخاصة بك.
3. شغل المشروع عبر Visual Studio واستخدم Swagger للمعاينة.
